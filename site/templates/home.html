What it does

Every agent, one place to look.

Each agent reports its state through its own hooks. omaorchestra shows which are working, which are waiting for you, and which are done, then starts the next task the moment one frees up.

Sessions at a glance

The bar counts working agents and turns urgent when one waits for you. Focus jumps to its terminal. Ended sessions stay in the History, searchable and resumable.

Start, queue and chain tasks

omaorchestra run or New task opens an agent in a new terminal. The queue starts tasks as slots free up, one after another if you chain them or run a recipe: build, then review.

Isolated worktrees

Each task in a git repository gets its own branch and worktree, ready to review, merge or discard when the agent is done.

Models and providers

Pick models per task or per folder, route Claude Code through the Anthropic API or OpenRouter, and see what every session costs against its budget.

MCP servers

One inventory across every agent, with health checks and per-task profiles. omaorchestra is an MCP server itself, too.

Handoffs

When an agent hits its limit, move the task to another agent or model, with a brief of exactly where it stands.

From your phone

Optional ntfy pushes when an agent needs you or a task finishes, only while you are away from the desk. omaorchestra top over SSH answers permission prompts and runs the queue.

Local and private

A user service behind a Unix socket with no open port, keys in the system keyring, and a native Qt app rather than a web page.

Get started

Running in a minute.

One package for every Omarchy machine, and one command to wire it into your desktop.

  1. 1

    Install the package

    Download the .pkg.tar.zst from the latest release; its SHA-256 is listed alongside.

    $ sudo pacman -U ~/Downloads/omaorchestra-*.pkg.tar.zst
$ sudo pacman -S --needed pyside6   # the app

  2. 2

    Connect your desktop

    Starts the service, adds each agent's hooks, and puts the widget on your bar. Safe to run again; --dry-run shows the changes first.

    $ omaorchestra setup

  3. 3

    Put agents to work

    Start a task now or queue it for when a slot frees up. Super Alt A jumps to whoever needs you.

    $ omaorchestra run "fix the flaky test" --in ~/code/app
$ omaorchestra queue add "update the dependencies" --in ~/code/app
